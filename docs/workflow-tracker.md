# Workflow tracker — spec-to-build

Stage-close entries are appended here by `/hand-off`. Do not edit by hand — if a stage needs
correcting, re-run `/hand-off` and note the correction in that entry rather than editing history.

This file, together with the journey log under `.forge/journey/`, is the audit trail `lab-grader`
and the facilitator use to see what actually happened, stage by stage.
